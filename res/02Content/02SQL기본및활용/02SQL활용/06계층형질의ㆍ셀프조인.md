### Oracle계층형질의

```sql
6. SELECT ...
1. FROM 테이블
5. WHERE condition AND condition ...
2. START WITH condition
3. CONNECT BY [NOCYCLE] codition AND condition ...
4. [ORDER SIBLINGS BY column, column, ...]
```

가상컬럼
- LEVEL
- CONNECT_BY_ISLEAF
- CONNECT_BY_ISCYCLE



순방향
```sql
SECECT LEVEL, LPAD(' ', 4*(LEVEL-1)) || 사원 사원, 관리자, CONNECT_BY_ISLEAF ISLEAF
FROM 사원 START WITH 관리자 IS NULL
CONNECT BY PRIOR 사원=관리자;
```

역방향
```sql
SECECT LEVEL, LPAD(' ', 4*(LEVEL-1)) || 사원 사원, 관리자, CONNECT_BY_ISLEAF ISLEAF
FROM 사원 START WITH 사원='D'
CONNECT BY PRIOR 관리자=사원;
```



제공함수
- SYS_CONNECT_BY_PATH

제공연산자
- CONNECT_BY_ROOT
  

```sql
SELECT CONNECT_BY_ROOT 사원 루트사원, SYS_CONNECT_BY_PATH(사원, '/') 경로, 사원, 관리자
FROM 사원
START WITH 관리자 IS NULL
CONNECT BY PRIOR 사원=관리자
```

## 셀프조인
```sql
SELECT ALIAS명1.칼럼명, ALIAS명2.칼럼명, ...
FROM 테이블1 ALIAS명1, 테이블2 ALIAS명2
WHERE ALIAS명1.칼럼명2 = ALIAS명2.칼럼명1;
```

Ex.
```sql
SELECT WORKER.ID 사원번호, WORKER.NAME 사원명, MANAGER.NAME 관리자명
FROM EMP WORKER, EMP MANAGER
WHERE WORKER.MGR = MANAGER.ID;
```
