## WINDOW FUNCTION 개요
WINDOW FUNCTION 종류
- 순위함수
- 집계함수
- 행순서함수
- 비율함수

WINDOW FUNCTION Syntax
```sql
SELECT WINDOW_FUNCTION (ARGUMENTS) OVER
( [PARTITION BY 칼럼][ORDER BY절] [WINDOWING절] )
FROM 테이블명;
```
